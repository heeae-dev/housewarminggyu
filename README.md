# 병규의 집들이 초대장

실제 병규 얼굴을 유지한 사진과 미연시 대화창으로 구성한 정적 웹페이지입니다.
빌드나 API 키 없이 브라우저에서 실행됩니다.

## 미리보기

`index.html`을 브라우저로 열거나, 프로젝트 폴더에서 다음 명령을 실행합니다.

```powershell
python scripts/package_site.py
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. 이 서버는 로컬 제작 확인용입니다.

## 동작

- 처음 접속하면 초대장이 도착하는 짧은 표지가 열립니다. 봉투를 누르면 긴 편지가 열리고, 편지 아래의 시작 버튼을 누르면 게임에 들어갑니다. 게임 상단의 “초대장 편지”에서 긴 편지를 다시 읽을 수 있습니다. 편지 내용은 `invitation-letter.js`의 백틱 사이 HTML에서 수정합니다. `<p>문단</p>`, `<br>` 줄바꿈, `<strong>강조</strong>`를 사용하며 마크다운의 `**`는 쓰지 않습니다.
- 제목, 행사 정보, 체크리스트는 각각 HTML 영역으로 구분했습니다. 고양이 문자 그림은 `<pre>` 안의 공백과 줄바꿈을 그대로 유지하세요. 화면에서 수정 결과를 보려면 저장 후 새로고침합니다.
- 긴 편지는 3초 후 초당 12px 속도로 자동 스크롤됩니다. 직접 스크롤하거나 “잠시 멈추기”를 누르면 멈추며, 운영체제의 동작 줄이기 설정에서는 자동 시작하지 않습니다.
- 봉투를 누른 뒤 편지의 시작 버튼을 누르면 병규 화면이 시작됩니다. 상단 “초대장 편지”로 편지 전문을 다시 읽을 수 있습니다.

- 첫 화면에서 핑크색 파자마를 입은 병규가 반깁니다.
- “어디로 가면 돼?”를 누르면 장소를 개인적으로 물어봐 달라는 답변이 표시됩니다.
- “언제 하는 거야?”를 누르면 2026년 10월 31일 19시부터 11월 2일 오전 8시까지, “0박 3일” 일정이 표시됩니다.
- “음식은 뭐 먹을거야?”를 누르면 프릴이 풍성한 분홍색 앞치마를 입고 치킨 접시를 든 사진과 함께 먹자는 대사가 나옵니다.
- 편지 또는 화면 하단에서 “나는 그냥 집들이 안 갈래”를 누르면 팔짱을 낀 흑화 병규와 어두운 화면의 BAD ENDING으로 끝납니다. 일반 선택지는 사라지고 “처음부터 다시 시작”으로 편지부터 다시 볼 수 있습니다.
- 화면 하단의 “좋아, 집들이 갈게!”를 누르면 두 팔을 펼쳐 반기는 병규와 HAPPY ENDING이 나옵니다. 해피 엔딩에서도 처음부터 다시 시작할 수 있습니다. 참석 선택은 연출용이며 서버에 참석 여부를 저장하지 않습니다.
- “다른 것도 물어볼래”로 선택지로 돌아갑니다.
- 실제 얼굴은 유지하고 하트 효과와 대사로 부끄러운 반응을 표현합니다.
- 선택지에 따라 사진도 전환됩니다. 장소 질문에는 두 손을 모은 자세, 일정 질문에는 손가락을 들어 설명하는 자세가 나타나고, 돌아가면 기본 사진을 보여줍니다. 세 사진 모두 원본 머리 사진을 합성했습니다.
- 키보드로 선택할 수 있으며, 운영체제의 동작 줄이기 설정을 따릅니다.

## 배포 파일

공개 파일만 담은 `dist/`를 만드는 명령:

```powershell
python scripts/package_site.py
```

GitHub Pages에는 `dist/` 내용만 배포합니다. `.env`, `.local/`, 원본 사진, API 스크립트는 포함하지 않습니다.
GitHub 저장소 연결과 Pages 공개 설정은 아직 하지 않았습니다.
